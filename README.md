# 벤치마크 코리아

컴퓨터 부품의 제품 사양, 가격, 성능을 검색하고 비교하기 위한 한국어 웹 사이트의 첫 화면입니다.

첫 화면은 따뜻한 종이 질감 위에 잉크 블루를 찍어낸 에디토리얼 스타일로 구성했습니다. 데이터 백과사전의 정보성은 유지하면서, 제품 검색·상세 보기·비교가 중심 흐름입니다.

## 지금 되는 기능

- 부품 카테고리 선택, 제품명·제조사·사양 검색
- 제조사 필터 및 성능/가격순 정렬
- 제품 상세 정보에서 사양·예시 가격·벤치마크·측정 환경 확인
- 2~4개 제품의 주요 사양·가격·벤치마크·출처 나란히 비교
- 데이터 출처 및 업데이트 기준 안내
- 데스크톱·모바일 화면 대응

## 실행 방법

`index.html`을 브라우저에서 열면 됩니다. 빌드 도구나 패키지 설치는 필요하지 않습니다.

## 데이터 안내

화면의 가격, 가격 변동률, 업데이트 날짜, 부품 개수, 벤치마크 지수는 모두 화면 흐름을 확인하기 위한 데모 값입니다. 실시간 시세나 공인 벤치마크로 사용하면 안 됩니다. 실제 서비스로 공개하기 전에 가격 출처별 수집 동의와 이용 조건을 확인하고, 측정 환경과 출처가 기록된 검증 데이터를 연결해야 합니다.

실제 제품 데이터는 제조사와 모델을 식별하는 제품 카탈로그에 저장하고, 판매처별 가격 제안과 가격 이력, 벤치마크 실행 결과는 각각 별도 레코드로 유지하는 구조를 권장합니다. 이 구분을 통해 동일 모델의 여러 판매 가격과 서로 다른 테스트 결과를 시간·출처와 함께 보존할 수 있습니다.

`data/schema.sql`은 PostgreSQL 기반 데이터베이스의 초안입니다. 이 정적 데모에는 데이터베이스나 자동 수집기가 연결되어 있지 않습니다.

## 다음 개발 단계

1. 데이터 제공처 및 사용 허가 범위 선정
2. 공식 제품 사양과 식별자 수집, 중복 제품 정리
3. 판매처 API 또는 허가된 피드 연동과 주기별 가격 이력 저장
4. 재현 가능한 벤치마크 결과 및 테스트 환경 기록
5. 데이터베이스 API, 관리자 검수 화면, 오류·갱신 모니터링 추가

어떤 단일 공개 피드도 “현재 판매 중인 거의 모든 컴퓨터 부품”과 한국 판매처 전부를 보장하지는 않습니다. 범위와 최신성을 정확히 표시하는 것이 데이터베이스 신뢰성을 만드는 데 중요합니다.
